# AI Root Cause and Decision Agent

An explainable AI system for correlating multi-source operational telemetry
(metrics + logs) to identify probable root causes of microservice incidents
and recommend evidence-grounded actions.

**Status:** In development (B.Tech Major Project)

## Research Gap
See `docs/research_notes.md` (added in a later phase) for the literature
review and the specific gaps this project targets.
